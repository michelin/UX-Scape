# 🎲 UX Scape – UX Print-Based Serious Game

## 🧠 Project Objective

This serious game is designed to raise awareness among a various population and profiles about key steps in the UX process through a fun and educational experience, entirely using print-based materials.

## 🕹️ Game Concept

- **Type**: mission board game + scenario booklet
- **Players**: 6 to 9
- **Average Duration**: 60 minutes of game + 30 minutes preparation and presentation + 30 minutes restitution
- **Required Materials**:
  - Printable resources and characters cards
  - Game board
  - Game booklet
  - Rules resume
  - Kaplas
  - Strings
  - Fabric sails
  - Sheets of paper
  - Pencils
  - PC and a timer

---

## 👥 Target Audience

- Product Owner or Product Managers
- Managers
- Project leaders
- Business or Functional Analyst
- Developers
- Anyone curious about UX design

## 💻 Digital Edition

UX Scape is also available as a standalone digital serious game. It introduces UX design through play: the crew has 40 minutes to discover one another's hidden needs, gather resources and build a raft that can get everyone safely off the island.


### ✅ Quick Start

1. Download [UXScape_digital_Version.html](UXScape_digital_Version.html).
2. Open it in a recent browser (Chrome, Edge, Firefox or Safari).
3. Select **New game**, enter the players' names and follow the on-screen instructions.

The game runs from a single HTML file on one shared screen, with no installation or server required. Its images, fonts, video teaser and sounds are embedded; the only external request is the Noto Sans font, with a system-font fallback when offline.


### 🎮 Digital Gameplay

- Supports 6 to 9 players and French or English, with a language switch on every screen.
- Includes a game-master panel and a dedicated private character reveal, followed by rounds for gathering resources, interviewing and UX observation.
- Provides an on-screen design studio for sketching and a grid-based raft builder for prototyping with gathered resources.
- Records events in a logbook, displays discovered constraints and clues, and lets the game master manage the timer and iterations.
- Designed for 1280 to 1920 px screens and remains usable on tablets and phones.

The digital edition is designed for about 40 minutes of play, plus approximately 15 minutes for setup and debrief. Game progress is not saved: reloading starts a new game; only the language choice is remembered. 
Character and item card illustrations and the video teaser are in French.
